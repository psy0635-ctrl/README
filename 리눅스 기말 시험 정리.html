01 SSH SSH 서버 — 원격 접속 포트 22 · Ubuntu → PuTTY
💡 SSH란? Windows(PuTTY)에서 Ubuntu 서버에 원격으로 들어올 수 있게 해주는 서비스. SSH 설치 후 PuTTY로 접속하면 이후 모든 작업을 Windows에서 할 수 있음.
명령어 순서 (Ubuntu 직접)
1
sudo apt install openssh-server
SSH 서버 설치
2
sudo vi /etc/ssh/sshd_config
SSH 설정 파일 열기
3
sudo systemctl restart ssh
설정 적용 (재시작)
4
sudo systemctl status ssh
active (running) 뜨면 성공
5
ip addr
내 IP 확인 — 192.168.xxx.xxx 형태
설정 파일 수정 — /etc/ssh/sshd_config
아래처럼 # 주석 제거해서 활성화
#Port 22 → Port 22
# 기호 = 주석(비활성화). 앞에 # 있으면 제거해야 적용됨
설정값의미
Port 2222번 포트로 접속 허용
ListenAddress 0.0.0.0모든 IP에서 접속 허용
WINDOWS 접속 — PuTTY
PuTTY 실행 → Host Name에 Ubuntu IP 입력 → Open
🎯 시험 주의: 시험에서는 SSH부터 해야 하지만, 연습 시에는 교수님이 준 PuTTY IP로 바로 접속하므로 SSH 설정 생략하고 FTP부터 진행하면 됨.
02 FTP FTP 서버 — 파일 전송 포트 21 · PuTTY → FileZilla
💡 FTP란? Windows(FileZilla)와 Ubuntu 사이에서 파일을 주고받게 해주는 서비스. SSH 접속 후 PuTTY에서 아래 명령어 입력.
명령어 순서 (PuTTY에서)
1
sudo apt install vsftpd
FTP 서버 설치
2
sudo vi /etc/vsftpd.conf
FTP 설정 파일 열기
3
sudo systemctl restart vsftpd
설정 적용 (재시작)
4
sudo systemctl status vsftpd
active (running) 확인
설정 파일 — /etc/vsftpd.conf
앞에 # 있으면 제거, 없으면 값 확인만
listen=YES ← 필수
listen_ipv6=NO ← 필수 (충돌 방지)
anonymous_enable=NO ← 익명 접속 차단
local_enable=YES ← 로컬 계정 접속 허용
write_enable=YES ← 업로드 허용
⚠ listen=YES면 listen_ipv6=NO 반드시 같이. 안 하면 vsftpd 실행 자체 안 됨.
설정값 전체 의미 정리
설정값의미중요도
listen=YESFTP 서버 켜기 (IPv4 방식)필수
listen_ipv6=NOIPv6 끄기 — listen=YES와 충돌 방지필수
anonymous_enable=NO익명(아이디 없이) 접속 차단 — 보안권장
local_enable=YESUbuntu 계정으로 로그인 허용필수
write_enable=YES파일 업로드(쓰기) 허용필수
FileZilla 접속 정보 (Windows)
항목입력값
호스트Ubuntu IP (192.168.xxx.xxx)
사용자명Ubuntu 로그인 아이디
비밀번호Ubuntu 로그인 비밀번호
포트21
입력 후 "빠른 연결" 클릭 → 파일 업로드/다운로드 테스트
03 Apache Apache 서버 — 웹 서버 포트 80 · PuTTY 설치 → Chrome 확인
💡 Apache란? 브라우저(Chrome)에서 웹페이지를 볼 수 있게 해주는 서비스. 설치하면 바로 동작 — 설정 파일 수정 불필요.
명령어 순서 (PuTTY에서)
1
sudo apt install apache2
Apache 웹 서버 설치 — 설치 즉시 자동 실행됨
2
sudo systemctl status apache2
active (running) 확인
3
Chrome → http://[Ubuntu IP]
Apache 기본 페이지 보이면 성공
Apache 핵심 정보
항목값
웹 루트 경로/var/www/html/
기본 페이지 파일index.html
접속 방법Chrome 주소창에 Ubuntu IP 입력
설정 파일 수정불필요 — 설치만 하면 동작
✓ 4개 서버 중 유일하게 설정 파일 수정 없이 바로 동작
index.html 만들어서 업로드하기
1
Windows 메모장 열기
원하는 HTML 내용 작성
2
파일 저장 시 설정
파일 이름: index.html  /  파일 형식: 모든 파일 선택
⚠ 파일 형식을 "모든 파일"로 안 하면 index.html.txt 로 저장됨
3
방법 A — FileZilla로 직접 업로드
오른쪽 원격 경로를 /var/www/html/ 로 변경 → index.html 드래그앤드롭
권한 오류 나면 → sudo chmod 777 /var/www/html
4
방법 B — 홈 폴더에 올린 후 PuTTY에서 복사
FileZilla로 홈 폴더(/home/계정명)에 업로드 → PuTTY에서:
sudo cp index.html /var/www/html/index.html
5
Chrome → http://[Ubuntu IP]
내가 만든 페이지가 보이면 성공
04 MariaDB MariaDB — 데이터베이스 서버 포트 3306 · PuTTY 설치 → HeidiSQL
💡 MariaDB란? 데이터를 저장·관리하는 창고 역할. MySQL과 거의 동일하며 명령어도 같음. 설치 + DB생성 + 외부접속 설정 3단계로 진행.
1단계 — 설치 및 보안 설정 (PuTTY에서)
1
sudo apt install mariadb-server
MariaDB 서버 설치
2
sudo mysql_secure_installation
보안 설정 — root 비밀번호, 외부 접근 설정 등
실행하면 질문이 나옴 → 대부분 Y로 답하면 됨
2단계 — DB 생성 및 사용자 설정
1
mariadb -u root -p
DB에 root 계정으로 접속 (-u = 사용자, -p = 비밀번호 입력)
2
use mysql;
mysql 시스템 DB 선택 — 접속 후 제일 먼저 실행
3
create database aiswtest;
aiswtest 이름의 DB(창고) 만들기
4
create user 'aiswdb'@'%' identified by '@Polytech';
어디서든(%) 접속 가능한 사용자 aiswdb 생성, 비밀번호 @Polytech
5
grant all privileges on aiswtest.* to 'aiswdb'@'%' with grant option;
aiswdb 사용자에게 aiswtest DB 전체 권한 부여
6
flush privileges;
권한 설정 즉시 적용 — 반드시 실행해야 함
7
exit;
DB 나가기
3단계 — 외부 접속 설정
1
sudo vi /etc/mysql/mariadb.conf.d/50-server.cnf
설정 파일 열기
아래처럼 수정:
bind-address = 127.0.0.1 → bind-address = 0.0.0.0
127.0.0.1 = 내 컴퓨터에서만 접속 가능
0.0.0.0 = 모든 IP에서 접속 가능
2
sudo systemctl restart mariadb
설정 적용
mysqld 아님 — Ubuntu에서는 반드시 mariadb
3
sudo systemctl status mariadb
active (running) 확인
HeidiSQL 접속 정보 (Windows)
항목입력값
네트워크 유형MariaDB or MySQL (TCP/IP)
호스트명/IPUbuntu IP (192.168.xxx.xxx)
사용자aiswdb
암호@Polytech
포트3306
"열기" 클릭 → 왼쪽에 aiswtest DB 보이면 성공
⚠ flush privileges 안 하면 HeidiSQL 접속 안 됨

07 QUIZ 시험 예상 문제 클릭하면 정답 공개
Q01서버 설치 전 제일 먼저 실행해야 하는 명령어 2개는? ▼
ANSWER
sudo apt update → sudo apt install vim
Q02SSH 설정 파일에서 Port 22를 활성화하는 방법은? ▼
ANSWER
#Port 22 에서 앞의 # 제거 → Port 22 로 수정
# = 주석(비활성화) 표시. 제거해야 설정이 적용됨
Q03FTP 설정 파일에서 반드시 써야 하는 핵심 3가지는? ▼
ANSWER
listen=YES · local_enable=YES · write_enable=YES
+ listen_ipv6=NO (listen=YES와 충돌 방지용으로 필수)
Q04anonymous_enable=NO 의 의미는? ▼
ANSWER
익명(아이디/비밀번호 없이) 접속을 차단하는 보안 설정.
NO = 익명 접속 불허 → Ubuntu 계정으로만 로그인 가능
Q05index.html 파일을 메모장에서 저장할 때 주의할 점은? ▼
ANSWER
파일 형식을 "모든 파일"로 선택해야 함
안 하면 index.html.txt 로 저장되어 웹페이지로 인식 안 됨
Q06FileZilla로 직접 업로드 안 될 때 대안 방법은? ▼
ANSWER
FileZilla로 홈 폴더에 먼저 업로드 → PuTTY에서:
sudo cp index.html /var/www/html/index.html
또는 권한 먼저 부여: sudo chmod 777 /var/www/html
Q07mariadb 접속 후 첫 번째로 실행해야 하는 명령어는? ▼
ANSWER
use mysql;
mysql 시스템 DB를 선택하는 명령어. 이걸 먼저 해야 이후 DB 생성 작업 가능
Q08bind-address 를 127.0.0.1에서 0.0.0.0으로 바꾸는 이유는? ▼
ANSWER
127.0.0.1 = 자기 자신(로컬)에서만 접속 가능
0.0.0.0 = 모든 IP에서 접속 허용 → Windows HeidiSQL에서 접속 가능해짐
Q09MariaDB 재시작 명령어는? (자주 틀림) ▼
ANSWER
sudo systemctl restart mariadb
❌ restart mysqld — Ubuntu/Debian 계열에서는 mysqld 아님
Q104개 서버 포트 번호를 모두 말하면? ▼
ANSWER
SSH 22 · FTP 21 · Apache(HTTP) 80 · MariaDB 3306
Q11내 HOST 번호를 확인하는 명령어는? ▼
ANSWER
PuTTY에서 hostname 입력하면 Class01-xx 형태로 표시됨
Q12Apache는 왜 설정 파일 수정이 필요 없는가? ▼
ANSWER
설치하면 포트 80, 웹 루트 /var/www/html/ 기본값으로 자동 실행되기 때문.
다른 서버들은 외부 접속 허용 등 기본값 변경이 필요해서 수정이 필요함.
