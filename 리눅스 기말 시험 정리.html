01 SSH SSH 서버 — 원격 접속 포트 22 · PuTTY로 접속
명령어 순서
1
sudo apt install openssh-server
SSH 서버 설치
2
sudo vi /etc/ssh/sshd_config
설정 파일 편집
3
sudo systemctl restart ssh
설정 적용 (재시작)
4
sudo systemctl status ssh
실행 중인지 확인
5
ip addr
내 IP 확인
설정 파일 — /etc/ssh/sshd_config
Port 22
ListenAddress 0.0.0.0
설정값의미
Port 2222번 문으로 접속
0.0.0.0모든 IP에서 접속 허용
Windows 접속 → PuTTY 실행 → IP 입력
02 FTP FTP 서버 — 파일 전송 포트 21 · FileZilla로 접속
명령어 순서
1
sudo apt install vsftpd
FTP 서버 설치
2
sudo vi /etc/vsftpd.conf
설정 파일 편집
3
sudo systemctl restart vsftpd
설정 적용
4
sudo systemctl status vsftpd
실행 확인
5
sudo chmod 777 /var/www/html
업로드 권한 오류 시 실행
설정 파일 — /etc/vsftpd.conf
listen=YES
listen_ipv6=NO
write_enable=YES
설정값의미
listen=YESFTP 서버 켜기 (IPv4)
listen_ipv6=NOIPv6 끄기 — 충돌 방지
write_enable=YES파일 업로드 허용
⚠ listen=YES인데 listen_ipv6=NO 안 하면 vsftpd 실행 안 됨
FileZilla 파일 업로드 경로
구분경로설명
원격 사이트 (리눅스)/var/www/html/여기에 index.html 올리면 됨
기본 접속 경로/home/aisw처음 연결 시 홈 디렉토리로 이동됨 — 직접 변경 필요
03 Apache Apache 서버 — 웹 서버 포트 80 · 브라우저로 확인
명령어 순서
1
sudo apt install apache2
Apache 설치 — 설정 파일 수정 없이 바로 사용 가능
2
브라우저 → http://[IP주소]
Windows 크롬에서 접속 테스트
3
/var/www/html/index.html
웹페이지 파일 위치 — FileZilla로 여기에 업로드
Apache 핵심 정리
항목값
웹 루트 경로/var/www/html/
기본 페이지index.html
접속 방법브라우저 주소창에 IP 입력
설정 파일 수정없음 — 설치하면 바로 실행됨
✓ Apache는 4개 중 유일하게 설정 파일 수정 없이 설치만 하면 바로 동작
04 DB MariaDB — 데이터베이스 포트 3306 · HeidiSQL로 접속
명령어 순서
1
sudo apt install mariadb-server
MariaDB 설치
2
sudo mysql_secure_installation
보안 설정 (root 비밀번호, 외부접근 차단 등)
3
mariadb -u root -p
DB 접속 (-u: 사용자, -p: 비밀번호 입력)
4
DB 내부 명령어 실행 (아래 표 참고)
DB 생성, 사용자 생성, 권한 부여
5
sudo vi /etc/mysql/mariadb.conf.d/50-server.cnf
bind-address = 0.0.0.0 으로 수정 (외부 접속 허용)
6
sudo systemctl restart mariadb
설정 적용 — mysqld 아니고 mariadb임 주의
DB 내부 명령어
create database aiswtest;
create user 'aiswdb'@'%'
  identified by '@Polytech';
grant all privileges on
  aiswtest.* to 'aiswdb'@'%'
  with grant option;
flush privileges;
exit;
명령어 뜻 정리
명령어뜻
create databaseDB(창고) 만들기
'aiswdb'@'%'어디서든(%) 접속 가능한 사용자
identified by비밀번호 설정
grant all privileges모든 권한 주기
flush privileges권한 즉시 적용
설정 파일
# /etc/mysql/mariadb.conf.d/50-server.cnf
bind-address = 0.0.0.0
0.0.0.0 = 모든 IP에서 DB 접속 허용
HeidiSQL 접속 정보
항목값
호스트192.168.xxx.xxx (리눅스 IP)
사용자aiswdb
암호@Polytech
포트3306
DBaiswtest
⚠ 재시작 명령어는 sudo systemctl restart mariadb — mysqld 아님. Ubuntu/Debian 계열은 mariadb가 정확한 서비스명.

05 QUIZ 시험 예상 문제 클릭하면 정답 보임
Q01SSH 서버 설치 명령어는? ▼
ANSWER
sudo apt install openssh-server
Q02SSH 기본 포트 번호는? ▼
ANSWER
22번 — 설정 파일: /etc/ssh/sshd_config에서 Port 22 확인
Q03FTP 설정 파일에서 반드시 추가해야 하는 3가지 설정값은? ▼
ANSWER
listen=YES · listen_ipv6=NO · write_enable=YES
listen_ipv6=NO 빠지면 vsftpd 실행 충돌 발생
Q04Apache 웹 서버의 기본 웹 루트 경로는? ▼
ANSWER
/var/www/html/ — 여기에 index.html 올리면 브라우저에서 바로 접속 가능
Q05MariaDB에서 외부 접속을 허용하려면 어떤 설정을 해야 하나? ▼
ANSWER
설정 파일 /etc/mysql/mariadb.conf.d/50-server.cnf 에서
bind-address = 0.0.0.0 으로 변경 후 sudo systemctl restart mariadb
Q06MariaDB 재시작 명령어는? (자주 틀리는 문제) ▼
ANSWER
sudo systemctl restart mariadb
❌ restart mysqld — Ubuntu에서는 mysqld 아님
Q07DB 사용자에게 권한을 부여하고 즉시 적용하는 명령어 2개는? ▼
ANSWER
grant all privileges on aiswtest.* to 'aiswdb'@'%' with grant option;
flush privileges; — flush 안 하면 재시작 전까지 권한 적용 안 됨
Q08FileZilla로 접속했는데 파일 업로드가 안 될 때 원인과 해결책은? ▼
ANSWER
원인: /var/www/html/ 폴더가 root 소유라 일반 사용자는 쓰기 권한 없음
해결: sudo chmod 777 /var/www/html
Q094개 서버의 포트 번호를 순서대로 말하면? ▼
ANSWER
SSH 22 · FTP 21 · Apache(HTTP) 80 · MariaDB 3306
Q10ListenAddress 0.0.0.0 의 의미는? ▼
ANSWER
모든 네트워크 인터페이스(모든 IP)에서 들어오는 접속을 허용한다는 뜻.
SSH, FTP, MariaDB 모두 같은 의미로 사용됨
