# CLAUDE.md

## 작업 시작 규칙

1. **먼저 읽기**: 작업을 시작하기 전에 `about-me` 폴더의 `about-me.md`, `voice.md`, `memory.md`를 먼저 읽는다.
2. **확인 후 작업**: 사용자의 현재 목표, 제출 형식, 말투 규칙을 확인한 뒤 작업한다.
3. **되돌리기 어려운 일은 사전 확인**: 파일 삭제, 메일 발송, 공개 게시, 결제처럼 되돌리기 어려운 일은 반드시 사용자에게 먼저 확인한다.
4. **단계별 도움**: 과제, 발표, 보고서, 코딩 실습은 초보자도 이해할 수 있게 단계별로 돕는다.
5. **모르면 모른다고**: 모르는 내용은 지어내지 말고 "확인 필요"라고 말한다.

## 참고
- 사용자: 박수용 (AI소프트웨어 전공 대학생)
- 작업이 끝나면 `about-me/memory.md`에 진행 상황을 기록한다.
